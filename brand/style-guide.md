# CASA 1569 — Visual Style Guide

## Creative direction

**Quiet Portuguese Luxury**  
supported by **Maritime Modernism** and **Old World Contemporary**.

The visual language should communicate place, provenance and hospitality without literal historic costume.

## Colour system

| Token | Hex | Role |
|---|---|---|
| Casa Ivory | `#F1EBDD` | Primary background |
| Atlantic Ink | `#17262C` | Primary typography / dark surfaces |
| Azulejo Blue | `#315E6D` | Cartographic and Portuguese accent |
| Patina | `#667063` | Botanical / São Miguel accent |
| Terracotta | `#A85D43` | Warm architectural accent |
| Aged Brass | `#A48656` | Premium detail / metallic reference |

### Approximate use ratio

- 55% Casa Ivory
- 30% Atlantic Ink
- 10% Patina / Azulejo
- 5% Aged Brass / Terracotta

## Typography

### Display serif
Use a refined high-contrast editorial serif.

Web-safe starting option:
- Cormorant Garamond

Potential professional brand-font direction:
- Canela-like
- Tiempos-like
- Portrait-like
- refined Baskerville lineage

### Supporting sans
Use a restrained modern sans.

Recommended:
- Inter
- Manrope
- Neue Haas / Suisse-like direction if licensed later

### Typography behaviour

- generous whitespace;
- limited weights;
- narrow body-copy columns;
- metadata in uppercase with measured tracking;
- coordinates and ROTA labels use sans;
- major origin names use serif.

## Graphic language

Use:
- coordinates;
- route numbers;
- fine cartographic lines;
- topography;
- restrained geometric tile logic;
- very thin dividers;
- lots of negative space.

Avoid:
- anchors;
- ropes;
- obvious compass logos;
- pirate maps;
- caravels as the main identity;
- bright blue-and-white tile wallpaper.

## Material language

- uncoated stock
- matte tin
- Portuguese limestone
- lime plaster
- linen
- dark timber
- glazed ceramic
- brushed / aged brass

## Photography

Origin-led, documentary and architectural.

Prioritise:
- São Miguel landscapes
- Atlantic water
- tea fields
- hands at harvest
- factories and tools
- mist
- soil
- ceramics
- natural light
- restrained interiors

Avoid generic influencer/wellness photography.

## Packaging direction

Primary tin:
- matte Atlantic Ink body;
- Casa Ivory wordmark;
- subtle aged-brass edge/detail;
- removable origin band;
- ROTA number;
- origin;
- tea type;
- coordinates;
- lot/harvest metadata.

ROTA 001 preferred band:
- Patina.
